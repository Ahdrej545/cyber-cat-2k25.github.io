 # Cyber Cat 2K25

Интерактивный фан-проект об интернет-культуре, мемах и неоновой эстетике.

## Возможности

- Адаптивный киберпанк-интерфейс.
- Переключаемые фоновые эффекты и поддержка системной настройки уменьшения анимации.
- Интерактивная схема распространения мемов.
- Локальный демонстрационный терминал: help, about, status, lore, theme, clear.
- Звуковой эффект из папки assets/sounds/.
- Навигация по разделам и мобильное меню.

## Запуск

Откройте cyber-cat 2k25/index.html в браузере. Для локального сервера запустите python3 -m http.server 8000 в корне репозитория, затем откройте http://localhost:8000/cyber-cat%202k25/.

## Структура

- cyber-cat 2k25/index.html — разметка страницы.
- cyber-cat 2k25/style.css — оформление и адаптивность.
- cyber-cat 2k25/script.js — интерактивность.
- cyber-cat 2k25/assets/sounds/ — звуковые эффекты.

## Примечание

Счётчики и терминал не показывают реальные метрики и не запускают системные команды. Это локальная визуальная симуляция. Исторические формулировки — творческая интерпретация, если отдельно не указаны проверяемые источники. Сайт рассчитан на статическую публикацию через GitHub Pages.

## v1.8 — резервная копия личной галереи

- Экспорт сохранённых мем-картинок и подписей в ZIP-файл.
- Восстановление галереи из ZIP с проверкой формата, размера PNG и контрольных сумм.
- Импорт выполняется локально и после подтверждения заменяет текущую галерею; перед восстановлением сохрани отдельную копию.
- ZIP использует несжатые PNG, чтобы обходиться без сторонних библиотек и внешних сервисов.

## v1.9 — отправка мемов PNG

- Кнопка «Поделиться PNG» в Meme Studio открывает системное меню отправки, если браузер поддерживает передачу файлов.
- Сохранённые мемы в личной галерее тоже можно отправлять напрямую.
- Если передача PNG не поддерживается, картинка скачивается обычным способом.
- Отправка выполняется по действию пользователя; изображения не загружаются на сервер Cyber Cat.

## v2.0 — устанавливаемое приложение и офлайн-режим

- Добавлен веб-манифест с именем Cyber Cat 2K25, иконками и режимом отдельного окна.
- Кнопка «Установить приложение» вызывает системный диалог в поддерживаемых браузерах и показывает подсказку для остальных.
- Service Worker сохраняет основные HTML/CSS/JavaScript-файлы и локальные ресурсы для повторного открытия без сети после первого успешного кэширования.
- Мемо-галерея и резервные копии по-прежнему хранят данные локально в браузере.
- Первое открытие и установка требуют сети; Google Fonts не обязательны для офлайн-интерфейса, поскольку используются резервные системные шрифты.

## v2.0.1 — исправление установки PWA

- Исправлена PNG-иконка 512×512, которая была повреждена в v2.0 и могла мешать распознаванию сайта как устанавливаемого приложения.
- Проверка CI теперь считывает размеры и проверяет CRC всех PNG-чанков обеих иконок, а не только наличие файлов.
- Кнопка установки показывает более понятные инструкции для Android, iOS и компьютера, если браузер не предоставляет автоматический диалог установки.
- Статус офлайн-режима теперь сообщает об успехе только после активации Service Worker, а не сразу после регистрации.
- Обновлены cache-busting версии ресурсов до 2.0.1.
